Anthropic’s documented vision interface accepts images; animated images use only their first frame. There’s also a practical advantage to code-based motion: we can keep the user’s actual screenshots and text intact, and expose controls for color, timing, and layout. The hard part becomes making generated code render reliably and remain editable.

**Before building the directory, I’d run one small experiment:** generate the same 15-second product demo with and without a reference, using the same product assets.
